隐私政策

青禾课表 运营者：陈霖修 联系邮箱：linsion07@126.com 更新及生效日期：2026 年 9 月 15 日 本政策适用于青禾课表的课表、专注、打卡、文件导入导出及桌面卡片功能。

1. 本机处理的信息与用途

你填写或导入的课程名称、教室、教师、时间、周次和学期设置用于生成课表；专注标题、计时时间、完成状态、学习记录、打卡日期与笔记用于计时和学习统计。应用还在本机记录功能开关、主题选择、新手提示进度和桌面卡片实例标识，用于记住选择并刷新卡片。只处理你主动提供或使用功能产生的信息，无需注册账号。

2. 存储与保留

上述信息保存在本应用的设备私有存储中，不上传至运营者服务器。本版没有账号系统、广告 SDK、行为统计 SDK或自建服务器。数据保存至你主动删除、清除应用数据或卸载为止；卸载、设备故障或清除数据可能导致本机记录丢失。建议自行备份，导出文件由你选择的保存位置和相关服务管理。

3. 文件与系统功能

导入 ICS 或恢复备份时，通过系统文件选择器读取你选择的文件；导出时仅写入你指定的位置，不扫描其他文件。应用不申请通讯录、相册、定位、麦克风、摄像头或系统日历权限。ArkUI/HDS 提供界面，Form Kit 提供桌面卡片，系统文件服务负责文件选择；这些功能不用于广告或画像。

4. 桌面卡片与实况窗

当你把课表卡片添加到桌面后，应用向鸿蒙桌面提交今日或本周的课程名称、时间、教室、课程跳转标识和更新日期用于展示，并记录卡片实例标识以便刷新。其他能看到你手机桌面的人也可能看到这些内容，可在桌面移除卡片。 本次发布未开放学习实况窗入口，不提交实况窗数据或主动申请通知许可。后续具备平台权益并开放该可选功能时，仅在你主动启用后申请通知许可，向鸿蒙 Live View Kit 提交专注标题、剩余时间、状态与任务标识，用于状态栏和锁屏显示。系统服务可能进行服务能力和应用权益校验，其平台侧处理受华为相应系统服务隐私声明约束。运营者不接收这些系统校验信息。你可在应用中关闭实况窗，也可在系统通知设置中关闭相关许可，基础课表仍可使用。

5. 共享与对外提供

运营者不会出售、出租你的学习信息，也不主动向其他个人或机构提供学习数据。你主动导出、分享备份，或把备份保存到第三方云盘时，接收方由你选择，其处理规则由相应服务决定。请妥善保管可能包含课程及学习记录的导出文件。

6. 你的选择与权利

你可以在课表中查看、修改、删除课程，在“我的”导出课表和学习记录；如需删除全部本机信息，可通过系统设置清除本应用数据或卸载。你可在“我的 → 设置 → 关于软件 → 撤回隐私同意”撤回系统签署记录，撤回不会自动删除课程与学习记录。导出到应用外的文件需在其保存位置另行删除。没有注册账号，因此不涉及账号注销。联系运营者可请求解释和协助；请勿主动发送无关的学籍、证件或其他敏感材料。

7. 未成年人

如你未满 14 周岁，请在监护人阅读并同意本政策后使用。监护人可协助管理、导出或删除设备中的学习信息，并通过联系邮箱咨询。本应用不要求提供年龄、身份证件、学号或真实学校身份。

8. 政策查看与联系

使用系统隐私托管后，首次进入由华为系统展示隐私提示；应用查询系统签署结果，同意后才开始业务。在“我的 → 设置 → 关于软件”通过系统返回的链接查看当前政策和用户协议。AppGallery Kit 提供协议链接和签署管理；正式分发版本通过系统配置的链接查看隐私页面；开发调试版本使用 GitHub Pages 提供的隐私说明进行系统弹窗联调。用户协议网页也由 GitHub Pages 托管（https://linsion07.github.io/qinghe-agreements/）。相应服务会接收提供网页所必要的网络请求信息，GitHub 的处理可能包括 IP 地址、设备及访问时间，详见 https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。网页未添加广告、统计脚本或第三方字体。课程与学习数据不随协议查询上传；平台侧网页访问或系统签署处理不等同于课表业务数据上传运营者服务器。若未来数据处理范围发生重要变化，将依法提供说明并在需要时重新征求同意。 有关隐私或本机数据管理的问题，请联系陈霖修：linsion07@126.com。
